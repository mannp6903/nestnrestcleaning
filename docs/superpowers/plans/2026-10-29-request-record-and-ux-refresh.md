# Request Record and UX Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Save every website form to a Google Sheet that Mann owns, without losing or duplicating requests. Also make the first-visit price lead the price box, add pets and notes to the final check, carry large-home details into the quote form, and prove the site works with bigger text, a keyboard and a screen reader as far as automated checks can.

**Architecture:**
- **Google Apps Script** (`tools/sheet/Code.gs`) is bound to the sheet. It receives a JSON POST, saves one row per submission (deduplicated by attempt ID under a script lock), then sends the alert and receipt emails. Triggers retry failed emails and send a morning reminder.
- **The site's `send()`** gains a `"sheet"` provider beside `"formsubmit"`. Every form passes its form name, a reference and an attempt ID, and keeps both across retries.
- **The other changes** are small edits to `tools/build.mjs`, `js/site.js` and `css/site.css`, each with browser tests in `tools/qa`.

**Tech Stack:**
- Static site generated by `tools/build.mjs`.
- Vanilla JS in `js/site.js`.
- Google Apps Script (V8).
- Node `vm` with stand-in Google services to test the script.
- Playwright and Chromium for browser tests.
- axe-core 4.10.2 (MPL-2.0), saved into `tools/qa/vendor`.

**Spec:** `docs/superpowers/specs/2026-10-29-request-record-and-ux-refresh-design.md`

## Global Constraints

- Brand, colours, type and layout stay as merged in PR #13, except the price box and the two new review rows.
- No invented reviews, photos, ratings or people.
- No personal details (name, phone, email, address, postal code, notes, referrer) in analytics payloads or page addresses.
- Every existing test keeps passing. `node tools/qa/perf.mjs` stays under LCP 2.2s and CLS 0.05.
- `node tools/build.mjs` regenerates every page; generated HTML is committed with the change that caused it.
- `js/config.js` keeps `delivery.provider: "formsubmit"` in this branch. The sheet switches on only when Mann's `/exec` address is added.
- `tools/sheet/Code.gs` is plain Apps Script: no `import`, no `require`, no Node APIs. Only the Google services listed in Task 1 are used.
- Receipt wording is fixed (Task 2), with only the reference filled in.
- Before merge: screenshots and a clickable preview for the owner (Task 8).

## Review Focus

1. **The browser request to Apps Script must be a CORS "simple request":** POST, string body, `Content-Type: text/plain;charset=utf-8`, no custom headers. Otherwise the real script fails every request on the live site, and nothing here would show it. Task 3 test `sheet request is a simple CORS request`.
2. **A double click on Send must never make two rows.** Both posts carry one attempt ID, and the script dedupes under its lock. Tests: Task 3 `double submit sends one attempt`, Task 1 `same attempt twice saves one row`.
3. **Mann will move, insert or rename columns in his sheet.** Writes go by header name, so rows still land under the right headers. Task 1 test `writes by header name after Mann moves columns`.
4. **Rows Mann has moved on are not reminders.** Rows marked Confirmed, Declined and so on must never appear in the morning reminder; only rows still Received after 2 hours do. Task 2 test `reminder lists only rows still Received after 2 hours`.
5. **Names and notes with accents, emoji and quotes** ("Zoë O'Brien 😊") are stored and emailed intact. Task 1 test `keeps accents, emoji and quotes intact`.

### Task 1: Sheet script — receive, validate, save

**Files:**
- Create: `tools/sheet/Code.gs`, `tools/qa/gas-fakes.mjs`, `tools/qa/sheet.test.mjs`

**Interfaces:**
- Produces, in `Code.gs` (top-level declarations, visible as context globals under `vm`):
  - `TABS = { booking: "Bookings", quote: "Quotes", gift: "Gifts", review: "Reviews", pricetext: "Price texts" }`
  - `STATUSES` (per tab, from the spec), `OWNER_COLUMNS = { Bookings: ["Confirmed time", "Final price"] }`
  - `SYSTEM_COLUMNS = ["Attempt", "Alert email", "Receipt email"]`, `KNOWN_FIELDS` (below), `REQUIRED` (below)
  - `now_() -> Date`; tests replace it.
  - `doPost(e) -> TextOutput`. It parses `e.postData.contents` and answers `JSON.stringify(handleRequest_(body))` as `ContentService.MimeType.JSON`. Bad JSON gives `{ ok: false, error: "Unreadable request" }`.
  - `handleRequest_(body) -> { ok: true, reference, duplicate } | { ok: false, error }`
  - `setup()`: creates missing tabs with headers in this order: `Reference, Received, Status, …OWNER_COLUMNS[tab], …KNOWN_FIELDS[form], …SYSTEM_COLUMNS`. It also makes row 1 bold and frozen, and puts the Status dropdown on rows 2+. Running it again changes nothing.
  - `headerMap_(sheet) -> { [header]: columnNumber }`
- Produces, in `gas-fakes.mjs`:
  - `loadScript({ props = {}, mailFailures = 0, now = new Date("2026-10-29T14:00:00Z") }) -> { ctx, sheet(name) -> { headers: string[], rows: object[] }, mails: object[], triggers: object[], setNow(Date) }`
  - Row objects are keyed by header.
  - The fakes implement only:
    - `SpreadsheetApp.getActive()` with `getSheetByName`, `insertSheet`, `getUrl` and `getSheets`; `newDataValidation().requireValueInList(list, true).build()`.
    - Sheet: `getName`, `getLastRow`, `getLastColumn`, `getRange(row, col, numRows?, numCols?)` with `getValues`, `setValues`, `setValue`, `setFontWeight` and `setDataValidation`; `setFrozenRows`.
    - `LockService.getScriptLock()` with `waitLock` and `releaseLock`.
    - `MailApp.sendEmail(obj)`; it throws while `mailFailures` remain.
    - `PropertiesService.getScriptProperties()` with `getProperty`, `setProperty` and `getKeys`.
    - `Utilities.formatDate(date, tz, fmt)` for `yyyy-MM-dd HH:mm` and `yyyy-MM-dd` in America/Toronto.
    - `ScriptApp.getProjectTriggers()`, `ScriptApp.newTrigger(fn)`, and the chain `.timeBased().everyMinutes(n)` or `.atHour(h).everyDays(1).inTimezone(tz)` ending in `.create()`; `trigger.getHandlerFunction()`.
    - `ContentService.createTextOutput(s).setMimeType(m)`, `ContentService.MimeType.JSON`.
  - `Code.gs` must use nothing else.

`KNOWN_FIELDS`, copied from today's form payloads:
- **booking:** Service, Home, Home notes, Extras, Included in this service, Plan, Preferred day, Preferred arrival window, Estimate, first visit, Estimate, repeat visits, HST, Price to confirm, Estimated time, Pricing version, Name, Phone, Email, Address, Postal code, Getting in, Pets, Products, Referred by, Notes, Confirm by
- **quote:** Service, Name, Phone, Email, Postal code, Notes
- **gift:** Amount, Send, Your name, Your phone, Email, Gift for, Their postal code, Their email, Message
- **review:** Rating, Name, Neighbourhood, Service, Review, Booked with
- **pricetext:** Text this price to, Quote, Estimated time, Page

`REQUIRED`. A value that is empty or "—" counts as missing:
- **booking:** Name, Phone, Address, Postal code.
- **quote:** Name, plus Phone or the top-level `email`.
- **gift:** Your name, plus Your phone or `email`.
- **review:** Name, Rating.
- **pricetext:** Text this price to.

**Request rules in `handleRequest_`:**
- `form` must be a key of `TABS`.
- `attempt` must match `/^[A-Za-z0-9]{16,40}$/`.
- Body over 20,000 characters (`JSON.stringify`): `{ ok: false, error: "Too large" }`.
- Non-empty `honey`: `{ ok: true, reference: body.reference || "", duplicate: false }`, with no row.
- `reference` must match `/^(NR|GIFT)-[A-Z0-9]{4}$/`; otherwise a new `NR-` reference is issued.
- Clash (same reference, different attempt): a new reference with the same prefix, using the alphabet `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`.
- Fields named like a reserved header (Reference, Received, Status, Confirmed time, Final price, Attempt, Alert email, Receipt email) are stored as `Form <label>`.
- `Email` is written from top-level `email`.
- Each value is cut to 2,000 characters. A value starting with `=`, `+`, `-` or `@` gets a leading `'`.
- Unknown labels add a column at the end.
- Received is `yyyy-MM-dd HH:mm`, Toronto time. Status is `Received`.
- The lock is held from the duplicate check through the write: `waitLock(10000)`.

### Task 2: Sheet script — emails, retries, reminder, setup guide

**Files:**
- Modify: `tools/sheet/Code.gs`, `tools/qa/sheet.test.mjs`
- Create: `docs/google-sheet-setup.md`

**Interfaces:**
- Consumes: Task 1's `handleRequest_`, `TABS`, `headerMap_` and `now_`.
- Produces:
  - `sendEmails_(tabName, rowNumber)`: fills Alert email and Receipt email.
  - `retryEmails()`: for the 15-minute trigger.
  - `morningReminder()`: for the 9am trigger.
  - `RECEIPTS`: the fixed wording.
  - `setup()` now also installs one `retryEmails` trigger (`everyMinutes(15)`) and one `morningReminder` trigger (`atHour(9).everyDays(1).inTimezone("America/Toronto")`), never two of either.

**When `handleRequest_` calls it:** after a new row is written and the lock is released. An email failure never changes the result `handleRequest_` returns.

**Email cell values:**
- `Sent`
- `Not sent (will retry, tries: N)`
- `Failed (gave up after 5 tries)`
- `Not needed`
- `Not needed (limit)`

**Alert email:**
- To: the `OWNER_EMAIL` script property, default `nestnrestcleaning@gmail.com`. `replyTo` is the customer's email when present.
- Subject by form:
  - booking: `New booking request <ref>`
  - quote: `New quote request <ref>`
  - gift: `New gift card request <ref>`
  - review: `New review <ref>`
  - pricetext: `New price text request <ref>`
- Body: one `Label: value` line per non-empty field, then `Open the sheet: <url>`.

**Receipt** (booking, quote and gift only, when `email` matches `/^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/`): the subject and first line are fixed, then the line `Nest & Rest Cleaning`.

| Form | Subject | Body line |
|---|---|---|
| booking | `We got your request <ref>` | `We got your request <ref>. It's not confirmed yet. Mann will reply within 2 hours during business hours to agree your time and final price.` |
| quote | `We got your quote request <ref>` | `We got your quote request <ref>. Mann will reply within one business day.` |
| gift | `We got your gift card request <ref>` | `We got your gift card request <ref>. Mann will text you within 2 hours during business hours to confirm and send an Interac e-Transfer request.` |

**Receipt limits.** Script properties `receipt:<lowercased email>` (time of the last receipt) and `receipts:<yyyy-MM-dd>` (that day's count):
- A second receipt to the same address within 60 minutes gives `Not needed (limit)`.
- The 51st receipt of a Toronto day gives `Not needed (limit)`.

**Morning reminder.**
- **Sent to** `OWNER_EMAIL`, subject `Waiting for your reply: <n>`. It's sent only when one of these exists:
  - a Bookings or Quotes row whose Status is exactly `Received` and whose Received time is more than 2 hours ago;
  - any row in any tab with a `Failed (gave up after 5 tries)` email.
- **Content:** one line per row (tab, reference, received time), then the sheet URL.

### Task 5: Pets and Notes in the final check

**Files:**
- Modify: `js/site.js` (`renderReview`), `tools/qa/booking.test.mjs`

**Interfaces:**
- Produces:
  - Rows `["Pets", radioVal("pets"), LAST, 'input[name="pets"]:checked']`, after Getting in.
  - Rows `["Notes", shortenAtWord(val("f-notes"), 200) || "None", LAST, "#f-notes"]`, after Products.
- `shortenAtWord(text, max) -> string`:
